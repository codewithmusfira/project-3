This project demonstrates how to overcome LLM knowledge limitations by feeding custom documentation into the generation pipeline.  🚀 Project OverviewThe goal of this project is to build a localized RAG system capable of loading text-based corporate policies, breaking them down into searchable units, and using a custom keyword search engine to provide accurate, context-driven answers through an LLM.  Key FeaturesDocument Loading & Processing: Automatically scans local directories to load and process raw text files using LangChain's document loaders.  Text Chunking Strategy: Implements RecursiveCharacterTextSplitter to break dense files into manageable 500-character chunks with a 50-character overlap to preserve natural boundaries and context.  Custom Keyword Retrieval: Uses a lightweight Python-based scoring algorithm built from scratch to find and rank the top matching text chunks based on query keywords.  Context-Constrained Generation: Links the retrieval system to OpenAI's gpt-3.5-turbo with a strict prompt structure that forces the model to reply only using provided context or state "not in context" to avoid hallucinations.  🛠️ Tech StackFramework: LangChain   LLM Provider: OpenAI API (gpt-3.5-turbo)   Environment Management: Python-dotenv   Development Environment: Jupyter Notebook (.ipynb)   📂 Project StructurePlaintext├── company_docs/            # Directory containing company policy .txt files
